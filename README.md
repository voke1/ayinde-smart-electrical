# Ayinde Smart Electrical - GitHub Pages

This folder is a complete static website. It has no build step, backend, or external dependency.

To publish it with GitHub Pages:

1. Copy the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch and the root folder, then save.

The phone, email, and Facebook links are already connected to Ayinde's contact details.
